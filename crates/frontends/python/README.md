# dengjen-tts-python

Python bindings to `dengjen-tts` using `pyo3`. Published to PyPI as `pydengjen`.

Install, voice download and a runnable example:
<https://zirekhq.github.io/en/dengjen-tts/main/start-python.html>. The example source is
[`examples/python/synthesize.py`](../../../examples/python/synthesize.py).
